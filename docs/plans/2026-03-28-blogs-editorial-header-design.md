# Blogs Editorial Header Design

## Goal

Add a cleaner editorial header to the public blogs page inspired by the provided reference image.

## Direction

The blogs page should open with a strong typographic header rather than immediately dropping into the existing feature grid. The new opening should feel lighter and more structured:

- a large title such as `Thinking Out Loud`
- a short supporting line under the title
- a slim utility row below with counts and controls

## Utility Row

The control strip should remain simple and right-weighted, similar to the reference:

- left side: compact counters for total published posts and available topics/categories
- middle/right: a lightweight dropdown for browsing topics
- far right: a simple pill search field and submit button

## Adaptation Rules

- Keep the site’s warm editorial palette instead of copying the reference directly
- Use restrained borders, generous spacing, and typographic contrast
- Make the controls feel like part of the page framing rather than admin filters
- Reuse existing data already available on the blogs page

## Scope

- Modify the public blogs page header composition
- Add the topic dropdown and simplified search surface
- Keep the rest of the blogs page structure intact

## Non-Goals

- Do not redesign the archive cards in this change
- Do not alter the query layer beyond passing data already being fetched
